# tame-gg

**[tame.gg](https://tame.gg)** is a Hypixel / Minecraft stats portal: player pages, trust tags, ranks, leaderboards, a Discord bot, and a partner API.

This org also ships related public work under the same brand: Minecraft server and proxy software, macOS apps, and a few co-branded web utilities. Most application source stays private; public repos and sites are linked below.

## Elsewhere in the org

### Minecraft

Performance and tooling for modded and vanilla networks:

- [conduit](https://github.com/tame-gg/conduit) - Velocity-CTD proxy fork
- [keila](https://github.com/tame-gg/keila) - Leaf/Paper performance server
- [SilkMC](https://github.com/tame-gg/SilkMC) - Folia-based multithreaded server
- [swordslauncher](https://github.com/tame-gg/swordslauncher) - Prism/MultiMC-lineage launcher
- [Universe](https://github.com/tame-gg/Universe) - cluster orchestrator

### macOS

Menu-bar and utility apps, plus a Homebrew tap:

- [NotchAgent](https://github.com/tame-gg/NotchAgent) - notch / menu-bar agent status
- [pulse](https://github.com/tame-gg/pulse) - Apple Silicon thermal / fan monitor
- [powerflow](https://github.com/tame-gg/powerflow) - power monitor
- [freshlock](https://github.com/tame-gg/freshlock) - app locker (Touch ID / password)
- [homebrew-tap](https://github.com/tame-gg/homebrew-tap) - `brew install --cask tame-gg/...`
